Compiler version 0.0.209 alpha for version 0.0.41 of the specs 2026/11/25

Changes from the previous version -----------------------
- Who can wait on a task (spec 20.2.6): a handle lent with & to a thread is lent from the start of the thread (it was from its first wait: the owner could wait before it). Tests taskowners and semaphore do not depend on time; *.dfc files are binary in git
- Numbers (spec 2.1, 3.5.1, 4.2, 13.2): type.MIN and type.MAX of the integer types, constants of that type; when no version of a function (of the program or built-in) matches, the only one that the automatic conversions reach is called with the level 3 warning, several are a compile error; substr, insert, remove, replaceAt, padLeft, padRight take uns (text.substr(position, word.len) needs no cast and gives no warning). Tests intlimits, autooverload, errors/autoconv_overload, intlimits_real
- indexOf and lastIndexOf of string (spec 4.2) take startPoint before caseSensitive, and give an int: text.indexOf("*/", position), text.indexOf("x", caseSensitive: false); indexOf("x", false) is a compile error. The position converts from any integer. Tests stringindexof, strings, errors/indexof_old_case
- Type switch (spec 11.3.7): a jump leaves it (jump #label#), a jump to another case of it is a compile error; in an enforce, break, continue and jump in a type switch are refused as anywhere else in its block. Tests switchtype, errors/switchtype_jump, switchtype_jump_default, switchtype_enforce_break
- Generics (spec 11.3.7, 10.5): switch value is ? { Type name: ... Type, Type: ... default: ... }, the statement form of the type switch, on set parameters, set values, objects and tasks. Fixed: the type switch on an object (obj is ? { Dog x: ..., default: ... }) was chosen by the declared type of the variable, now by the class of the object when the program runs (a null object goes to default); a type switch on a set value without default in a function that raised nothing else. CodeGen.TypeSwitches.cs, tests switchtype, errors/switchtype_missing, switchtype_not_member, switchtype_object_missing, switchtype_bind_two
- Generics (spec 11.3.6): a set value (a variable, a field, an item, a result) given to a parameter of the same set chooses the copy of the function by its tag when the program runs, for functions, methods and static ones, methods of structs, several parameters; a value never assigned raises UnassignedTypeException. Fixed: a type switch on a set value whose cases give nothing made C that did not compile. CodeGen.SetDispatch.cs, tests setdispatch, errors/setdispatch_typeparam

Fixed: with the catches of both TaskAlreadyTerminatedException and TaskWasNotStartedException (or of the first one around a call through the handle) a timeout skipped the rest of the code the catches cover. Test waitvar
- Wait (spec 20.2.8): var r = wait t timeout 500 { several lines, return }: the type is the one of what the wait gives (tasks, threads, signal groups, calls through the handle); with a written type too it takes objects and arrays now, and r owns what it gets. Fixed: an object kept by var d = wait t was never ended; the timeout block of a wait on a call through the handle was ignored; var r = wait t inside a function did not know its type when t is declared in the same scope. Tests waitvar, errors/wait_var_wrong_value, wait_var_signal
- Order of the arguments (spec 2.5, 11.1.5.1): the object and the arguments of the built-in methods and of the standard library run from left to right in the order of the parameters (they could run in any order); make().f(g()) runs make() first; the values of a struct given by name run in the order of its fields. Tests argorder, stringargs
- Strings as values, inside a statement (spec 2, 4): the operands of an operator run from left to right also when only the right one has effects (k.label + k.change()); a text read by a part of a call, an operator, an interpolated string, a literal or a multiple assignment takes its copy when a later part can change it; a loop variable keeps its text when the body changes the collection (by its name, another name or a call), and so does the text that for char c in text goes through.
