Calculating values using expressions and producing formatted output

Working with numbers, casts, and expressions


i32 a = 12
r64 b = 15.5

i32 allInteger = a + (i32)b * 2
r64 allFloat = (r64)a + b * 2
r64 complicated = (r64)a / 3 + b * 2.13

Root.Console.log($"Casting to integers gives {allInteger}\nCasting to floats gives {allFloat:d4}.\nAnd the complicated number is {complicated:d5}")
i32 is an integer value of 32 bits, same as int from C#
r64 is a floating point numeric value, same as double from C#
(i32) is a cast it is used to transform one type to another.
The final result is an interpolated string where some parts inside the string are replaced with variables (and formatted if needed).
Interpolated strings start with $ and have the variables and expressions inside braces { } Run →
